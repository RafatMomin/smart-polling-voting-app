# Smart Polling & Voting App

A full-stack mobile polling and voting application designed to provide a secure, interactive, and user-friendly voting experience. This project was developed as part of a university team project and demonstrates real-world mobile, backend, and system integration concepts.

---

## 📱 Project Overview
🎥 **App Demo Video:**  
https://www.youtube.com/watch?v=RlSfbTIuS_M

The **Smart Polling & Voting App** allows users to:
- Create and participate in polls
- View live voting results
- Interact through discussions and dashboards
- Access location-aware and secure voting features
- Experience a modern Android UI connected to a scalable backend

The system follows a client–server architecture with an Android frontend and a Spring Boot backend.

---

## 🏗️ Tech Stack

### Frontend (Android)
- **Language:** Java / Kotlin  
- **Framework:** Android SDK  
- **Tools:** Android Studio  
- **Features:**
  - User authentication
  - Poll creation and voting
  - Live results visualization
  - Interactive dashboards
  - Clean and responsive UI

### Backend
- **Language:** Java  
- **Framework:** Spring Boot  
- **Architecture:** RESTful APIs  
- **Features:**
  - User management
  - Poll and vote handling
  - Data persistence
  - Real-time communication support
  - Secure API endpoints

## 🚀 Getting Started

### Prerequisites
- Android Studio (latest version recommended)
- Java JDK 11+
- Gradle
- Spring Boot compatible IDE (IntelliJ IDEA recommended)
- Git

---

### Running the Backend
1. Navigate to the `Backend/` directory
2. Open the project in your IDE
3. Configure environment variables if required
4. Run the Spring Boot application

---

### Running the Frontend
1. Open the `Frontend/` folder in Android Studio
2. Sync Gradle files
3. Connect an Android device or start an emulator
4. Run the app
